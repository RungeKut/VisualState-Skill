# Снимок диаграммы без помехи человеку

Нужен набор HiddenDesktop-Kit (`HDKIT_HOME`; скилл `hidden-desktop` — там
вся механика и ловушки).

```python
import vskit as vk
vk.designer_shot(vsp, "all.png", zoom=50)                       # обзор
vk.designer_shot(vsp, "sheet.png", zoom=100,                    # лист
                 open_path=[0, 0, 0, 0, 0, 3])
vk.designer_shot(vsp, "page2.png", zoom=100, scroll_pages=1)    # ниже
```

## Что делается
1. Control Center запускается на скрытом столе
   (`ControlCenter(desktop=HiddenDesktop())`), он же запускает Designer —
   окно наследует стол и человеку не видно.
2. Окно возвращается из развёрнутого состояния и растягивается до
   `max_window_size()` (3860x1100): HiddenDesktop-Kit 30-05, 30-09.
3. Лист региона: двойной клик `PostMessage` по узлу дерева проекта;
   `open_path` — путь индексов (проект, система, автомат, регион, верхнее
   состояние, регион-лист).
4. Документ растягивается на область MDI. Нулевое вложенное окно НЕ
   трогать ([30-11](../30_ГРАБЛИ/30-11_растянутое_вложенное_окно_документа_закрашивает_диаграмму.md)).
5. Масштаб — выпадающий список (ctrl id 33054): пункты 1000, 750, 500,
   400, 300, 200, 100, 75, 50, 25, 10, 5 %; выбор `CB_SETCURSEL` +
   `WM_COMMAND`. Масштаб действует на АКТИВНЫЙ документ — выбирать после
   открытия листа.
6. Снимок `PrintWindow` всего окна; Designer закрывается `quitDesigner`.

## Как смотреть
Вы видите картинку ≤ 2000 px по длинной стороне. Обзор — 50 % целиком;
детали — 75–100 % и вырезка `img.crop(...)` не шире ~2000 px; одна
проверка на фрагмент (HiddenDesktop-Kit 20-01).

## Как неправильно
* Запускать Designer обычным `launchDesigner` на столе человека:
  окно перехватывает фокус.
* Уводить окно за край экрана — снимок обрезан (HiddenDesktop-Kit 30-04).
* Менять масштаб до открытия листа — масштаб применится к другому документу.
