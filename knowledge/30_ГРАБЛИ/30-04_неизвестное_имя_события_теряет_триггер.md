# Пропавший триггер

## Что происходит

1. В format 6/8 триггер ссылается на событие именем. Опечатка
   `<trigger name="evNoSuchEvent"/>` не даёт ошибки «нет события»:

   ```
   Transition without any trigger: 'Playing: [currentTrack == lastTrack] / -> NotPlaying'.
   Coder completed - 1 error(s)                код 1
   ```

   HCoder: `Transition without any trigger: 'Playing -> NotPlaying'.`

2. Переход из псевдосостояния выбора (`choiceState`) с одним guard, без
   отметки `<triggerLessTransition/>` и пустого `<trigger/>`:
   Verificator — 0 ошибок, Validator симулирует, а HCoder:

   ```
   Error: Transition path from 'Sel.Region1.choice1' to 'Sel.Region1.Run' has no trigger.
   Error: Linker errors found, aborting.
   ```

   Так пишет и Designer: в примере AVSystem ветка выбора с guard —
   `<triggerLessTransition/>` + `<conditionSide><trigger/><guards>…`,
   ветка else — `<elseTransition/>`.

## Как правильно

* Имена событий, действий и состояний сверять ДО Coder: `Machine.check()`
  / `Project.save()` в `vskit.design` отказывают с понятным текстом
  («нет события 'evB'»).
* В описании: `m.trans(choice, "X", None, guard=...)` — vskit сам ставит
  triggerless; `otherwise=True` — else. Переход без события из обычного
  состояния — только явно `triggerless=True`.

## Как неправильно

Искать, почему «переход без триггера», в самом переходе — смотреть надо
имя события в `trigger`.

## Чем подтверждено

12.10.2026: `tests/test_coder.py` (неизвестное имя -> код 1 и «without any
trigger»), `tests/test_design.py` (выбор с guard и else — HCoder,
Verificator, Validator OK).
