# Порядок элементов

## Что происходит

Записали состояние так: entryReactions, exitReactions,
internalTransitions, externalTransitions. HCoder:

```
(File '...\CDPlayer.vsr') At line 375 Column 19, element 'internalTransitions'
is not allowed for content model '(expl,alias,position,stateProperties,
entryReactions?,internalTransitions?,exitReactions?,externalTransitions?,
regions?,tags?)'
код 1
```

lxml по той же схеме: `Element 'exitReactions': This element is not
expected. Expected is one of (regions, tags).`

## Почему

Разбор XML в Visual State идёт со строгой схемой (`xs:sequence`); у
`stateVertex` формата 11 порядок: expl, alias, position, stateProperties,
entryReactions, internalTransitions, exitReactions, externalTransitions,
regions, tags.

## Как правильно

Писать модель через `vskit.design` (порядок соблюдён) и проверять
записанное схемой: `vk.schema_check(vsp)` — это делает `Project.save()`
и `full_check`. При ручной правке XML — та же проверка до Coder.

## Как неправильно

Править .vsr текстом «как удобнее», полагаясь на то, что XML-парсеры
порядок не замечают.

## Чем подтверждено

12.10.2026: первая версия `vskit.design` дала эту ошибку на CDPlayer с
добавленным внутренним переходом; после исправления — OK.
`tests/test_model.py` переставляет `exitReactions` в копии и ждёт отказа
схемы и HCoder.
