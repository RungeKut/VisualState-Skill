# Работа с репозиторием

Набор создан как локальный git-репозиторий; удалённого (GitHub) пока нет —
публикует владелец, когда решит. Правила ниже действуют уже сейчас: всё
закоммиченное должно быть пригодно для публичного репозитория.

## Порядок

```bash
cd "$VSKIT_HOME"
git pull --rebase                                        # если есть удалённый
# ... правки набора ...
git diff                                                 # прочитать глазами
python tools/check_docs.py --project "<папка проекта>"   # стоп-слова
git add -A && git commit -m "что и почему"
git push                                                 # только если есть удалённый и это решено
```

## Изделие в набор не попадает

Убирается всё, по чему узнаётся изделие:

* название, децимальный номер, имена файлов и папок проекта;
* **имена из его модели**: автоматы, состояния, события, действия,
  переменные, их пояснения; назначение режимов;
* протоколы, команды, назначение выводов МК;
* пути, серверы, учётные записи.

Остаётся: поведение Visual State, командные строки, коды, примеры на
`examples\` поставки или на отвлечённых моделях («кнопка», «лампа»).
Проверки на рабочем проекте — только через `tests/test_project.py` с
путём аргументом; вывод — в `tests/vyvod/` (в `.gitignore`).

### Стоп-лист — только локальный

`tools/stoplist.txt` в `.gitignore`, заводится `setup.ps1`, у каждой
машины свой. Новое изделие — строка туда **до** первого коммита.
`check_docs.py` считает ошибкой и отсутствие файла, и его возвращение под
git (`git rm --cached tools/stoplist.txt`).

`check_docs.py --project "<папка>"` добавляет к стоп-словам имя папки,
имена `.vsp/.vsr` в ней и подпапках и **имена внутри моделей** (системы,
автоматы, состояния, события, действия, переменные — целиком, от 5
символов, кроме служебных `initial1`, `Region1`...). Хук `commit-msg`
проверяет текст коммита по стоп-листу и `git config vskit.project`.

### Автор коммита — задан для клона

```bash
git config user.name  "<публичное имя>"
git config user.email "<публичный адрес>"
```

Без этого git возьмёт глобальные (рабочие) имя и адрес. `check_docs.py`
требует автора на уровне клона. Не задан — не коммитить, а спросить
человека.

**`gh auth login` из агентской оболочки не запускать** — висит без
терминала.

## Чем подтверждено

12.10.2026: первичные коммиты; `check_docs.py --project` по папке рабочего
проекта — имена его автомата и событий в стоп-словах, расхождений нет.
