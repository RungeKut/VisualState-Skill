# Работа с репозиторием

Набор — `https://github.com/RungeKut/VisualState-Skill`, ветка `main`.
**Порядок, обезличивание, стоп-лист, автор, соавторы, форк и разбор PR,
GitHub без gh — соседний скилл skill-skill, `knowledge/40_СРЕДА/40-02` и
40-03.** Коротко: в начале `git -C <корень> pull --rebase`; после правки
`git diff` глазами → `python tools/check_docs.py --project "<папка
проекта>"` → `git add <файлы>` → `git commit` → **`git push` сразу**.

## Обезличивание: модель изделия

Кроме общего списка, в набор, текст коммита и PR не попадают:

* **имена из модели изделия**: системы, автоматы, состояния, события,
  действия, переменные, их пояснения (`note=`); назначение режимов;
* протоколы, команды, назначение выводов МК;
* **снимки диаграмм и окон рабочего проекта** (Designer, Validator): на
  картинке читаются имена, а стоп-лист картинки не видит. Снимки — во
  временной папке сессии или в `tests/vyvod/` (в `.gitignore`).

Остаётся: поведение Visual State, командные строки, коды, примеры на
`examples\` поставки (CDPlayer, AVSystem) или на отвлечённых моделях
(«кнопка», «лампа»). Проверка на рабочем проекте — только
`tests/test_project.py` с путём аргументом; вывод — в `tests/vyvod/`.

## Имена из моделей в стоп-словах

`check_docs.py --project "<папка>"` добавляет к стоп-словам имя папки,
имена `.vsp/.vsr` в ней и подпапках и **имена внутри моделей** (системы,
автоматы, состояния, события, действия, переменные — целиком, от 5
символов, кроме служебных `initial1`, `Region1`…) — это делает
`tools/kit_local.py`. Папку проекта можно запомнить для клона:
`git config visualstate.project "<папка проекта>"` — её учитывают и
`check_docs.py`, и хук.
