# Установка и окружение

## Клон

Общий порядок (папка скиллов агента, хук, автор, стоп-лист, обновление) —
соседний скилл skill-skill, `knowledge/40_СРЕДА/40-01`. Для этого набора:

```bash
cd "<папка скиллов>"
git clone https://github.com/RungeKut/VisualState-Skill.git visualstate
git clone https://github.com/RungeKut/HiddenDesktop-Skill.git hidden-desktop   # снимки Designer
git clone https://github.com/RungeKut/MCU-Skill.git mcu                        # GCC, по желанию
cd visualstate
git config core.hooksPath ../skill-skill/hooks
git config user.name  "<публичное имя>"
git config user.email "<публичный адрес>"
python tools/check_docs.py
```

Свой стоп-лист набора — `tools/stoplist.txt` (локальный, в `.gitignore`),
вдобавок к общему skill-skill; приметы изделий — туда до первого коммита.

## Соседние скиллы

`vskit` ищет их только по соседству с корнем набора, переменные окружения
не читает (skill-skill, 30-01):

| Сосед | Папка | Зачем | Нет его |
|---|---|---|---|
| hidden-desktop | `<родитель корня>\hidden-desktop` (`vskit.shot.hd_root()`) | `vk.designer_shot`, `ControlCenter(desktop=HiddenDesktop())` | `ShotError` с командой клона |
| mcu | `<родитель корня>\mcu` (`vskit.env.mcu_root()`) | `mcukit.gcc_bin()` — где arm-none-eabi-gcc | GCC ищется в `VSKIT_GCC`, затем в PATH |

## Python и пакеты

Python 3.11+ **64-bit** (StateMachineAPI64.dll грузится только им). lxml —
для проверки схемой, ставится руками:

```bash
python -m pip install --user lxml
```

Без lxml всё работает, кроме `vskit.schema` (`full_check` пишет
«ВНИМАНИЕ»).

## Где что лежит

`C:\Program Files (x86)\IAR Systems\Visual State 9.1\` (`vk.vs_root()`;
другая папка — `VSKIT_VSROOT`):

| Путь | Что |
|---|---|
| `bin64\HCoder.exe`, `Coder.exe` | кодеры, без окон ([10-02](../10_API/10-02_coder_и_hcoder_из_командной_строки.md)) |
| `bin64\Verificator.exe` | формальная проверка, без окон ([10-03](../10_API/10-03_verificator_из_командной_строки.md)) |
| `bin64\Documenter.exe` | документ по модели (RTF/HTML), без окон — в наборе не используется, не проверен |
| `bin64\ProjectConverter.exe` | `ProjectConverter.exe <проект.vsp> <папка>` — перевод старых форматов; не проверен |
| `bin64\ControlCenter.exe` | JSON-RPC сервер для Validator/Designer ([10-04](../10_API/10-04_control_center_validator_designer.md)) |
| `bin64\Validator.exe`, `Designer.exe`, `Navigator.exe` | оконные программы |
| `bin64\StateMachineAPI64.dll` | C API модели ([10-05](../10_API/10-05_state_machine_api_и_схема.md)) |
| `doc\UserGuide.chm`, `UserGuide.pdf` | руководство (раздел «Classic Coder command line options», «Hierarchical Coder…», «Control Center») |
| `doc\StateMachineAPI\` | заголовок и HTML API |
| `examples\` | примеры (только читать): CDPlayer, AVSystem (format 6/8) |
| `license\` | LMS2 (LicenseManager.exe) |

Версия — `vk.version()` (заголовок Coder.exe). Лицензия — `vk.license_ok()`
([30-01](../30_ГРАБЛИ/30-01_license_check_only_код_1.md)).

## Компилятор

`vk.gcc_bin()`: `VSKIT_GCC` (папка bin) -> `mcukit.gcc_bin()` из соседнего
скилла mcu -> `arm-none-eabi-gcc` в PATH. На машине проверки (2026-10-12)
— GCC 10.3.1 из STM32CubeIDE, найден через mcukit.

## Переменные (необязательные)

Только настройки программ, не поиск наборов:

| Переменная | Что |
|---|---|
| `VSKIT_VSROOT` | папка Visual State, если не в стандартном месте |
| `VSKIT_WORK` | рабочая папка заданий (без пробелов и кириллицы); по умолчанию `%LOCALAPPDATA%\Temp\vskit` |
| `VSKIT_GCC` | папка bin с arm-none-eabi-gcc |
| `VSKIT_TEST_VSP` | проект для `tests/test_project.py` |

## Проверка окружения

```bash
python -c "import sys, platform; sys.path.insert(0, '.'); import vskit as vk; vk.utf8_console(); print(platform.architecture()[0], vk.__version__, vk.vs_root(), vk.version(), vk.license_ok()[0]); print(vk.gcc_version(), vk.gcc_bin())"
```

Из корня набора. Ожидается `64bit`, версия Visual State и `True`
лицензии; GCC не найден — `RuntimeError` с подсказкой. Затем — `tests\`
(README).

## Время операций (машина проверки)

HCoder/Coder — 0.1–0.3 с; Verificator — 0.1 с на примерах; компиляция
двух файлов — около 1 с; запуск Validator через Control Center — 1–2 с;
`designer_check` — 8 с ожидания плюс запуск.

## История

До 0.4.0 (2026-10-28) установщик `tools/setup.ps1` создавал junction из
папок скиллов агентов в `<корень>\skill`, переменную `VSKIT_HOME`, включал
хук и ставил lxml; соседей искали через `HDKIT_HOME`, `MCUKIT_HOME` и
жёсткий путь. Отказались: переменная пережила перенос клона и вела в
пустоту (skill-skill, 30-01). Теперь клон и есть папка скилла.
