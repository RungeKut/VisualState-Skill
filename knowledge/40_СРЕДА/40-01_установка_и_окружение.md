# Установка и окружение

## Где что лежит

`C:\Program Files (x86)\IAR Systems\Visual State 9.1\` (`vk.vs_root()`;
другая папка — `VSKIT_VSROOT`):

| Путь | Что |
|---|---|
| `bin64\HCoder.exe`, `Coder.exe` | кодеры, без окон ([10-02](../10_API/10-02_coder_и_hcoder_из_командной_строки.md)) |
| `bin64\Verificator.exe` | формальная проверка, без окон ([10-03](../10_API/10-03_verificator_из_командной_строки.md)) |
| `bin64\Documenter.exe` | документ по модели (RTF/HTML), без окон — в наборе не используется, не проверен |
| `bin64\ProjectConverter.exe` | `ProjectConverter.exe <проект.vsp> <папка>` — перевод старых форматов; не проверен |
| `bin64\ControlCenter.exe` | JSON-RPC сервер для Validator/Designer ([10-04](../10_API/10-04_control_center_validator_designer.md)) |
| `bin64\Validator.exe`, `Designer.exe`, `Navigator.exe` | оконные программы |
| `bin64\StateMachineAPI64.dll` | C API модели ([10-05](../10_API/10-05_state_machine_api_и_схема.md)) |
| `doc\UserGuide.chm`, `UserGuide.pdf` | руководство (раздел «Classic Coder command line options», «Hierarchical Coder…», «Control Center») |
| `doc\StateMachineAPI\` | заголовок и HTML API |
| `examples\` | примеры (только читать): CDPlayer, AVSystem (format 6/8) |
| `license\` | LMS2 (LicenseManager.exe) |

Версия — `vk.version()` (заголовок Coder.exe). Лицензия — `vk.license_ok()`
([30-01](../30_ГРАБЛИ/30-01_license_check_only_код_1.md)).

## Python и пакеты

Python 3.11+ **64-bit** (StateMachineAPI64.dll грузится только им), lxml —
для проверки схемой (`setup.ps1` ставит). Без lxml всё работает, кроме
`vskit.schema` (`full_check` пишет «ВНИМАНИЕ»).

## Компилятор

`vk.gcc_bin()`: `VSKIT_GCC` (папка bin) -> `mcukit.gcc_bin()` из MCU-Kit
(`MCUKIT_HOME`, затем `E:\Skills\MCU-Kit`) -> `arm-none-eabi-gcc` в PATH.
На этой машине — GCC 10.3.1 из STM32CubeIDE (найден MCU-Kit).

## Переменные

| Переменная | Что |
|---|---|
| `VSKIT_HOME` | корень набора (ставит setup.ps1) |
| `VSKIT_VSROOT` | папка Visual State, если не в стандартном месте |
| `VSKIT_WORK` | рабочая папка заданий (без пробелов и кириллицы); по умолчанию `%LOCALAPPDATA%\Temp\vskit` |
| `VSKIT_GCC` | папка bin с arm-none-eabi-gcc |
| `VSKIT_TEST_VSP` | проект для `tests/test_project.py` |

## Подключение агентов

`tools\setup.ps1` создаёт junction'ы `~\.claude\skills\visualstate` и
`~\.kimi-code\skills\visualstate` -> `<корень>\skill` (без прав
администратора). Для opencode — вручную:

```powershell
cmd /c mklink /J "$env:USERPROFILE\.config\opencode\skills\visualstate" "<корень>\skill"
```

Junction — на `<корень>\skill`, а не на корень (иначе в агента уйдёт весь
репозиторий с `.git`); копию вместо junction не делать. Проверять
`Test-Path "$env:USERPROFILE\.claude\skills\visualstate\SKILL.md"` —
PowerShell 5.1 не заходит в junction при `Get-ChildItem -Recurse`.
`description` в SKILL.md — в кавычках (двоеточие с пробелом ломает YAML).
После первой установки — перезапуск агента.
