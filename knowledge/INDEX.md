# Индекс базы знаний

Плоская карта базы. Читается целиком за один раз, по ней выбирается нужный
файл. Заголовки сформулированы утверждениями — часто ответ виден уже отсюда.

Правила ведения базы — [00_ПРАВИЛА.md](00_ПРАВИЛА.md).

Статусы: **П** — проверено на реальном Visual State; **НП** — не
проверено; **У** — устарело.

---
