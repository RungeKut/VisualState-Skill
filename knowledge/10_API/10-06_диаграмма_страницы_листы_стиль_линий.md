# Страницы, листы, стиль линии (format 11)

## Страницы — рабочая область диаграммы
`<view colorNumber="7" pagesHorz="2" pagesVert="2"/>` у `region` (и у
проекта/системы) — размер холста в страницах бумаги (A4 портрет,
~2000 x 2850 единиц рабочей области на страницу, границы страниц видны
пунктирными линиями на диаграмме). **Содержимое за пределами сетки —
масштаб Designer перестаёт работать** ([30-10](../30_ГРАБЛИ/30-10_масштаб_не_работает_если_диаграмма_больше_сетки_страниц.md)).
`vskit.design` пишет `pagesHorz = max(2, ceil((w + MARGIN) / 2000))`,
`pagesVert = max(2, ceil((h + MARGIN) / 2850))` по размеру региона.

## Лист региона: offPage
`<region ... offPage="true">` — содержимое региона открывается в отдельном
окне диаграммы (в Designer: контекстное меню региона → Off-Page). В
родителе остаётся колонка-заглушка с именем региона и комментарием; её
ширина и высота — `<size width= height=>` региона. Внутри листа начало
координат — левый верхний угол листа (без отступа под заголовок родителя).
Верхний регион системы (`Region1` под системой) всегда `offPage="true"`.
Лист открывается двойным кликом по узлу региона в дереве проекта
([20-05](../20_ПРИЁМЫ/20-05_снимок_designer_на_скрытом_столе.md)); заголовок
окна: `<Система>.<Автомат>.Region1.<Состояние>.<Регион> - (State machine
diagram)`.

Правило vskit: регионы составного состояния с двумя и более регионами —
offPage, если через границу региона не идёт ни один переход; `size`
заглушки 700 x 260.

## Стиль линии перехода
`transitionProperties/properties value`:

| value | вид | проверено |
|---|---|---|
| 809894016 | ломаная по точкам (по умолчанию в vskit) | да |
| 809894017 | плавная кривая (сплайн) через точки маршрута | да, 3 точки: начало, изгиб, конец |
| 809894018 | ортогональная ломаная (прямые углы) | да |

Остальные значения (…019, …020, …024, …032, …048) на тестовой модели
рисовались как ломаная — отдельного вида не дали.

## Как неправильно
Оставить `pagesHorz="2"` для больших диаграмм; ждать, что `offPage` сам
уменьшит родителя (колонка-заглушка берёт `size` региона); задавать
сплайну две точки (кривая выйдет прямой).
