## 2026-10-12 — VisualState-Kit 0.1.0

Первая версия. Всё ниже проверено на IAR Visual State 9.1.1.3863.

* **Библиотека `vskit`**: разбор модели форматов 1–11 (`model`); запись
  автомата из описания на Python в format 11 и правка существующей модели
  с сохранением GUID (`design`); HCoder и Coder над копией (`coder`);
  Verificator с разбором .vre (`verificator`); Validator и Designer через
  Control Center (`sim`); компиляция arm-none-eabi-gcc с разбором
  внешних символов (`build`); State Machine API через ctypes (`smapi`);
  проверка XML схемой, вырезанной из HCoder.exe (`schema`); общий отчёт
  `full_check` (`report`).
* **База знаний**: 10-01…10-05, 20-01…20-03, 30-01…30-08, 40-01, 40-02.
  Главные находки: модель — открытый XML со схемой внутри программ, её
  можно писать скриптом; Validator пакетного режима не имеет, но
  управляется через Control Center (JSON-RPC, строка с переводом строки);
  совпадение имён проекта и системы молча ломает код при коде 0;
  Verificator с неизвестной системой — код 0; `VSMProjectSave`
  переписывает оригинал .vsr; неизвестное имя события теряется молча;
  ветки выбора требуют `triggerLessTransition`; без `IncludeExcluded` в
  .vws Validator открывает модальное окно.
* **Оснастка**: `tools/setup.ps1` (UTF-8 с BOM, junction на
  `<корень>\skill`, lxml), `check_docs.py` (стоп-слова, в том числе имена
  из моделей проекта), хук `commit-msg`, локальный стоп-лист.
* **Проверки** `tests/` на примерах поставки и на моделях, которые строят
  сами; `test_project.py` — любой проект по пути аргументом.
* **Шаблон** `templates/new_machine`: `model.py` (кнопка с долгим
  нажатием) + `build.py` (модель, проверки, код, сценарий в Validator).
